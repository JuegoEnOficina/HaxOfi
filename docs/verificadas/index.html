Salas verificadas

Un check azul en la lista de salas de haxball.com para las salas verificadas por su comunidad. Las copias que usan su nombre para sacarte la IP no lo tienen.

Descargar extensión

Cómo instalarla

  1. Descomprimí el zip en una carpeta.
  2. En Chrome abrí chrome://extensions y activá el Modo de desarrollador.
  3. Tocá Cargar descomprimida y elegí la carpeta.
  4. Entrá a haxball.com/play. Las salas verificadas ya muestran el check.

Funciona en Chrome, Edge, Brave y Opera. Pronto en la Chrome Web Store.
