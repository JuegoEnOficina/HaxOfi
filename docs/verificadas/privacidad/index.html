Política de privacidad

HaxOfi Salas Verificadas, extensión para Chrome. Última actualización: 4 de noviembre de 2026.

Resumen

La extensión no recopila, guarda, vende ni comparte datos personales. No usa cookies, no guarda nada en tu navegador y no tiene analíticas ni publicidad.

Qué hace

Solo corre en la página de juego de haxball.com. Ahí lee la lista de salas que la propia página ya descarga (nombre, jugadores, contraseña y bandera de cada sala) para poner un check azul al lado de las salas verificadas. Esa lectura se hace en tu navegador y no sale de él.

Qué se conecta

Para saber qué salas están verificadas, la extensión descarga una lista pública desde api.haxofi.com/rooms/verified, como mucho una vez por minuto. Ese pedido no lleva ningún dato tuyo: no envía tu nombre, tu cuenta, las salas que mirás ni a cuáles entrás.

Como pasa con cualquier pedido a un sitio web, el servidor recibe la dirección IP desde donde se hace. HaxOfi la usa solo para limitar el abuso del servicio y no la asocia a ninguna persona ni la comparte con nadie.

Permisos

La extensión no pide permisos de Chrome. Solo tiene acceso a las páginas de juego de haxball.com, que es donde muestra el check.

Cambios

Si la extensión cambia lo que hace con datos, esta página se actualiza antes de publicar la nueva versión.

Contacto

Por cualquier consulta escribinos a contacto@haxofi.com.

Privacy policy (English)

HaxOfi Salas Verificadas does not collect, store, sell or share personal data. It uses no cookies, no browser storage, no analytics and no ads.

It runs only on the haxball.com game page, where it reads the room list that page already downloads (each room's name, players, password flag and country flag) to show a blue check next to verified rooms. That reading happens in your browser and never leaves it.

To know which rooms are verified it downloads a public list from api.haxofi.com/rooms/verified, at most once a minute. That request carries no data about you: not your name, your account, the rooms you look at or the rooms you join. Like any web request, the server sees the IP address it comes from. HaxOfi uses it only to limit abuse of the service and does not tie it to any person or share it.

The extension requests no Chrome permissions beyond access to the haxball.com game pages. If what it does with data ever changes, this page is updated before the new version is published. Contact: contacto@haxofi.com.
